# -1-TS-
使用 TypeScript 开发地牢爬行游戏。网格 10×10，玩家角色（@）用 WASD 移动，每次移动消耗一步。怪物（G）随机移动，攻击玩家（战斗为自动判定，攻击力-防御力）。玩家有生命值、攻击力、防御力、饥饿值（步数限制，归零则每次移动扣血）。每层需找到钥匙（随机位置）然后到达楼梯进入下一层。目标分数（杀敌数 + 宝藏）每层累积。随机障碍块（陷阱：踩到扣血，墙：不可通行）。道具（随机出现在地上）：血瓶（回复生命）、炸弹（3×3 范围伤害）、传送（随机位置）。无限关卡（难度随层数上升）。本地保存最高到达层数和总分。提供三套主题（洞穴、墓地、神殿）。界面简洁，回合制无卡顿。
